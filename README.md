# Casa 3D — Proposta acadêmica

## Sobre o trabalho

Este projeto está sendo desenvolvido para a disciplina de **Planejamento e Controle de Obras (PCO)**. A proposta é planejar uma residência e apresentar o modelo 3D como apoio visual para explicar o projeto ao professor.

## Modelo interativo

O arquivo `index.html` apresenta uma visualização 3D da casa. Na página, é possível marcar ou desmarcar as camadas de:

- Água fria;
- Esgoto sanitário;
- Instalação elétrica.

## Etapa do projeto

Este modelo é um início do projeto e poderá ser atualizado conforme o trabalho avançar. A visualização serve como apoio acadêmico; os dados e as instalações ainda precisam ser conferidos e desenvolvidos nos projetos técnicos correspondentes antes de qualquer execução real.
